## ⬇️ Kurulum

1. Yukarıdaki **Windows için İndir** butonuna tıklayın.
2. Açılan sayfada **`ilksms-eokul-Setup-x.x.x.exe`** dosyasını indirin.
3. İndirilen dosyaya çift tıklayıp kurulumu tamamlayın.
4. Masaüstündeki **İlksms - Eokul Entegrasyonu** kısayolundan açın.

> 💡 Windows "Bilinmeyen yayıncı" uyarısı verirse **Daha fazla bilgi → Yine de çalıştır** deyin.

## ▶️ Nasıl çalışır?

- Uygulama açılınca **MEBBİS giriş ekranı** gelir; kendi MEBBİS bilgilerinizle giriş yaparsınız.
- Giriş sonrası e-Okul işlemleriniz uygulama içinden yürür.
- İşlemler doğrudan **sizin bilgisayarınızdan** yapılır.

## 🔄 Otomatik güncelleme

Uygulama her açılışta yeni sürümü **kendisi kontrol edip kurar** — tekrar indirmenize gerek yoktur.

## 💬 Destek

Bir sorunla karşılaşırsanız okul yöneticinizle veya İlksms destek ekibiyle iletişime geçin.
